## 🏛️ What It Does
**Trey Kampot (ត្រីកំពត)** is a free, mobile-friendly self-guided digital heritage walking tour exploring the French colonial-era architecture, Sino-Khmer commercial shophouse traditions, and riverside landmarks of Kampot, Cambodia.

### Key Features:
1. **Curated 1.6 km Heritage Walk (6 Stops)**:
   - **Stop 01**: Durian Roundabout (*Agricultural Identity & Civic Monument*)
   - **Stop 02**: Hotel Old Cinema (*1930s Chinese Opera House to Boutique Hotel*)
   - **Stop 03**: Cai-coffee (*Street 700 Shophouse Coffee Pause*)
   - **Stop 04**: Phsar Kronat (*1920s–30s Old Market Quarter*)
   - **Stop 05**: Starbucks Kampot Fish Market (*1934 Streamline Moderne Vault*)
   - **Stop 06**: Entanou Bridge (*Historic Old French Bridge Sunset Walk*)
2. **Before & After Archival Sliders**:
   - Compare 1920s French Indochina colonial blueprints and photographs side-by-side with modern drone photography.
3. **Sounds of Kampot (Vintage Cambodian Music)**:
   - In-page audio streaming of 8 classic 1960s–70s recordings by Sinn Sisamouth and Ros Serey Sothea.
4. **Bilingual Experience**:
   - 100% complete bilingual support in English and Khmer (ភាសាខ្មែរ).
5. **Interactive Q&A & Community Feedback**:
   - Frequently asked questions and traveler review submission.

## 🛠️ Tech Stack
* **Framework**: Next.js 14 (App Router)
* **Language**: TypeScript, React 18
* **Styling**: Tailwind CSS
* **Audio**: Native Web Audio API + YouTube Audio Streamer
* **Hosting**: Firebase Hosting (Static Export, Spark Free Plan)

## 🚀 Running Locally
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
# Open http://localhost:3000

# Build static export for production
npm run build
```
Output static files are exported to the `/out` directory.
